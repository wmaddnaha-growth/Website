## 📌 01. ملخص المشروع والداشبورد

تم بناء الموقع الإلكتروني الكامل مضافاً إليه **لوحة تحكم إدارية شمولية ومستقلة (Admin Dashboard)** للتحكم في كافة محتويات المنصة والمنتجات والأسعار والطلبات والأسئلة والمدونة وحصص الوقف الخيري (30%).

---

## 🔑 02. تسجيل الدخول ولوحة التحكم (Admin Panel)

- **رابط صفحة الدخول الإدارية:** `/admin/login`
- **كلمة المرور الافتراضية:** `admin123` (يمكن تغييرها عبر متغير البيئة `ADMIN_PASSWORD`).
- **رابط اللوحة الرئيسية:** `/admin`

---

## 🛠️ 03. مميزات لوحة التحكم (Admin Dashboard Features)

1. **اللوحة الرئيسية والمؤشرات (`/admin`):**
   - إجمالي المبيعات والإيرادات بالـ EGP.
   - إجمالي عدد الطلبات ونسبة الطلبات المكتملة.
   - إجمالي المبالغ المستقطعة لصالح الوقف الخيري (30%).
   - جدول أحدث الطلبات المسجلة مع إمكانية معاينة وتغيير الحالة فوراً.
   - أزرار إجراءات سريعة لإضافة كتب، أسئلة، ومقالات.

2. **إدارة المنتجات والكتب والأسعار (`/admin/products`):**
   - عرض جميع الأدلة (شفرة الرجالة، شفرة النساء، باكدج البيت السوي).
   - تعديل الأسعار المباشرة والأصلية بنقرة واحدة (Quick Price Edit).
   - إضافة كتاب أو دورة جديدة عبر نموذج الشاشة (`/admin/products/new`).
   - تعديل المحتوى الكامل والفصول والدروس والمميزات وشارات العرض (`/admin/products/[id]/edit`).

3. **إدارة الطلبات والمبيعات (`/admin/orders`):**
   - عرض كافة الطلبات مع إمكانية التصفية حسب الحالة (قيد الانتظار، مكتمل، تم الشحن، ملغي).
   - محرك بحث برقم الطلب، اسم المشتري، رقم الهاتف، أو البريد الإلكتروني.
   - نافذة تفاصيل الطلب واستعراض المنتجات المشتراة وتغيير حالة التسليم الشحن.

4. **إدارة الأثر وحصة الوقف 30% (`/admin/waqf`):**
   - متابعة مبالغ الوقف الخيري التلقائية المستقطعة من أرباح المبيعات.
   - تحديث مؤشرات المشاريع الإنتاجية وعدد الأسر المستفيدة.

5. **إدارة الأسئلة الشائعة (`/faq`):**
   - إضافة أسئلة وأجوبة جديدة وتصنيفها (عامة، المنتجات، الوقف، الشحن).
   - تعديل أو حذف أي سؤال فوراً.

6. **إدارة المدونة والمقالات (`/admin/blog`):**
   - كتابة ونشر مقالات إثرائية جديدة مع تحديد الكاتب، التصنيف، وزمن القراءة.

7. **إعدادات الموقع العامة والأسعار (`/admin/settings`):**
   - تعديل عناوين الهيرو والنصوص الرئيسية للموقع.
   - التحكم في الأسعار الافتراضية للكتب والباكدج.
   - تفعيل/إيقاف بوابات الدفع المصرية (كروت بنكية، كود فوري، المحافظ الإلكترونية).
   - تحديث بيانات التواصل والواتساب والبريد الإلكتروني.

## 🔌 04. محرك وحفظ البيانات (API & Store Layer)

تم إنشاء محرك حفظ وحفظ تلقائي في المجلد المحلي `data/store/` عبر مسارات Next.js API Routes:
- `/api/admin/auth` -> تسجيل الدخول وتوثيق الجلسة.
- `/api/admin/products` -> قراءة، إضافة، تعديل، وحذف المنتجات.
- `/api/admin/orders` -> قراءة الطلبات وتحديث الحالة.
- `/api/admin/faq` -> قراءة، إضافة، تعديل، وحذف الأسئلة الشائعة.
- `/api/admin/blog` -> قراءة، إضافة، تعديل، وحذف المقالات.
- `/api/admin/settings` -> قراءة وتحديث إعدادات الموقع والأسعار.
- `/api/admin/stats` -> جلب المؤشرات الإحصائية المحدثة لحظياً.
- `/api/checkout` -> استقبال وتسجيل الطلبات الجديدة وتوليد حصة الوقف (30%).

## ⚡ 05. التشغيل محلياً

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل سيرفر التطوير
npm run dev

# 3. بناء نسخة الإنتاج الخالية من الأخطاء
npm run build
npm run start
```

الموقع العام: `http://localhost:3000`
لوحة التحكم: `http://localhost:3000/admin`
